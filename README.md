## Программа calc.py

Консольный калькулятор на Python.
Возможности: сложение, умножение и вычитание двух чисел (целые и дробные).

Запуск:

    python calc.py 2 3

Ожидаемый вывод:

    2.0 + 3.0 = 5.0
    2.0 * 3.0 = 6.0
